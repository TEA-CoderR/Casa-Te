## 二、商品名称清理

在测试库上模拟了一遍（没有真的改）：11,494 个上架商品里，有 **1,302 个**名称会变。

- **只改格式，不改意思。**
- ERP 原名一直保存在 `erp_name` 字段里，随时可以恢复。
- 后台手工改过的名称不动。

### 1. 尺寸（846 个）
数字之间的 `x` 或 `*` 改成 `×`。原名里写了 cm（前面的"Cm."或后面的"cm"），才统一写成"… cm"；原名没写单位的，不加单位（可能是毫米）。单位是 cm 时，去掉表示高度的"h"。

|---|---|
| Panca Pieghevole Cm. 180x28x44h | Panca Pieghevole 180×28×44 cm |
| Barbecue rettangolare Cm. 58x38x82h C/Ripiano | Barbecue rettangolare 58×38×82 cm C/Ripiano |
| P/Bottiglia Classic cm 9x9x38h assortiti | P/Bottiglia Classic 9×9×38 cm assortiti |
| Set 3 Lampadine Solari Dia. Cm. 6x9h | Set 3 Lampadine Solari Dia. 6×9 cm |

不改的：表示包数的"Fazzoletti 6X9""Felix 4X85"，毫米尺寸"45x16x9 mm"。

### 2. 名称末尾的供应商编码（616 个）

- 大写字母加至少三位数字（"C1913""C12T6""C0244""4PZ374"）；
- 带横线的编码（"Yd-19803-A""Jh-5155"）；
- 紧跟在"cm"后面的数字或编码（"Padella 22 cm 9908""Mobile 3 Cas 30×24×61 cm Qb12485c"）。
